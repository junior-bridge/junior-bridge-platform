# Changelog

Todos los cambios significativos realizados en *JuniorBridge* serán documentados en este archivo.

El formato se basa en *Keep a Changelog* y el proyecto adopta *Semantic Versioning (SemVer)* como criterio para la identificación de versiones.

## [Unreleased]

### Added

- Estructura inicial del proyecto JuniorBridge.
- Organización del proyecto en un repositorio compartido.
- Estructura de trabajo para el desarrollo del frontend y backend.
- Documentación inicial del proyecto mediante README y Wiki.
- Definición de la estrategia de branching para el desarrollo colaborativo.
- Incorporación de documentación correspondiente a Sprints, casos de uso, criterios de aceptación y trazabilidad.

### Changed

- Actualización de la documentación del proyecto para incorporar criterios de Gestión de la Configuración.
